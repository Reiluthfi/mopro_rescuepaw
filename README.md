## Aturan Git (Wajib Dibaca)

- **Jangan** commit atau push langsung ke branch `dev` dan `main`.
- Setelah clone, langsung pindah ke branch personal masing-masing:

  ```bash
  git switch personal/<nama>
  ```

- Alur kerja: `personal/<nama>` → `dev` → `main`
- Buka Pull Request untuk setiap merge, dan minta satu teman mengecek sebelum di-merge.
- Sebelum mulai kerja, update branch dulu:

  ```bash
  git merge origin/dev
  ```
